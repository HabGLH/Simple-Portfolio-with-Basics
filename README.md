## 🌟 Highlights & Features

- **⚡ Lightning Fast & Zero Build Tooling**: 100% Vanilla HTML5, CSS3, and JavaScript — no heavyweight bundlers required, ultra-fast initial render.
- **🎨 Modern Dark & Light Mode**: Persistent theme switcher using `localStorage` and OS preference detection (`prefers-color-scheme`).
- **📱 Fully Responsive**: Custom fluid layouts designed for mobile (320px+), tablet, laptop, and ultra-wide displays using modern CSS Grid and Flexbox.
- **♿ High Accessibility (a11y)**: Semantic landmark elements, skip links, ARIA controls, WCAG AA color contrast, and keyboard navigation support.
- **🚀 Interactive Terminal**: Interactive developer JSON card with one-click clipboard copy utility.
- **💼 Comprehensive Project Showcase**: Live demo and GitHub source code links with architectural outcomes for each featured application.
- **📬 Interactive Contact Form**: AJAX submission powered by Formspree with real-time client-side validation and seamless email client fallback.

---

## 🛠️ Tech Stack & Architecture

- **Markup**: HTML5 (Semantic landmarks: `<header>`, `<main>`, `<section>`, `<article>`, `<footer>`)
- **Styling**: CSS3 with CSS Custom Properties, Flexbox, Grid, Glassmorphism, Fluid Typography (`clamp()`)
- **Scripting**: Vanilla JavaScript (ES6+ modular IIFE, IntersectionObserver API, Clipboard API)
- **Typography**: Sora (Display headings), Manrope (Body), JetBrains Mono (Code/Terminal)
- **Icons**: Optimized inline SVGs for zero render-blocking requests

## 🚀 Local Development

To run and preview the portfolio locally:

```bash
# Clone the repository
git clone https://github.com/HabGLH/Simple-Portfolio-with-Basics.git

# Navigate to project directory
cd Simple-Portfolio-with-Basics

# Start a local HTTP server (Python 3)
python3 -m http.server 8000
```

Open your browser and navigate to `http://localhost:8000`.
